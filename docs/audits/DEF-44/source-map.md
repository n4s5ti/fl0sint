## Existing contracts and exact gaps

### Acquisition interchange (graph-free wheel boundary)

- `flowsint-core/src/flowsint_execution/acquisition.py:63-144` defines strict/frozen `ContractModel`, `InputOccurrence`, and operation/caller/scope-bound `AcquisitionRequest`, including capability, endpoint, projection, and retention *digests*. These are declarations only; the documented public boundary explicitly does not retrieve or authorize artifacts (`docs/developers/acquisition-contract.md:1-7`).
- The existing equivalents of the requested names are `ArtifactReference` and `SpanReference`, not `SourceArtifact`/`SourceSpan`: `acquisition.py:164-207`. Artifact metadata has digest, byte length, locator, source family/origin, retrieval/event times, and requested/final URL. It has **no body, storage handle semantics, expiry/revalidation state, truncation flag, retention decision, or resolver authority**. Span is either one raw byte range or one JSON pointer; it cannot express exact raw-byte-to-normalized-character/byte mappings.
- `EvidenceReference` and `CandidateReference` (`acquisition.py:210-223`) preserve occurrence ownership and force `unreviewed`. `OccurrenceOutcome` and statuses (`acquisition.py:226-349`) provide `RETENTION_HOLD` but no explicit `REVIEW`/revalidation disposition for missing, expired, digest-tampered, or truncated artifacts.
- `_BundlePayload.check_reference_graph` (`acquisition.py:353-418`) validates artifact → span → evidence → candidate and occurrence ownership. It already permits many occurrences/evidence records to share an artifact/span while candidates remain occurrence-owned. This is the right base for body deduplication, but it does not persist an occurrence-to-artifact lineage table outside the bundle.
- `_digest`, `AcquisitionBundle.check_origin_digest`, parsing, serialization, and `build_bundle` (`acquisition.py:421-459,471-575`) detect malformed/tampered bundles and revalidate before wire output. Digest mismatch is only `malformed_contract`; it does not yield an operational REVIEW/revalidation result. The public contract and canonical digest rules are documented at `docs/developers/acquisition-contract.md:31-84`.
- Existing standalone entrypoint `flowsint-core/examples/acquisition_contract.py:15-151` writes/reads a controlled local source itself, then builds metadata. It does not share any retrieval/retention implementation with WebsiteToText. Packaging already includes `flowsint_execution` in the core wheel (`flowsint-core/pyproject.toml:45-53`), so a graph/service-free implementation belongs in that namespace.

Keep the bundle body-free. Preserve strict parse/serialize/build validation, digest coverage, and artifact sharing with occurrence-owned evidence. Do not rename/remove v1 fields without a format-version change.
2. **P2 — one graph-free capture/resolution implementation.** Add `flowsint-core/src/flowsint_execution/artifacts.py` with a narrow `ArtifactStore` protocol and a filesystem/in-memory implementation suitable for standalone use. `capture_authorized_source(operation, caller, retention_decision, body, metadata)` should content-address the body, atomically deduplicate bytes by SHA-256, and append immutable per-occurrence lineage. `resolve_authorized_source(operation_id, caller_id, artifact_ref, expected_digest, policy)` must re-check caller/scope/retention/expiry and digest on read. Return typed states, never a raw exception. A resolver capability/store path stays runtime-private and is never serialized.
3. **P3 — retention authority.** Introduce a trusted, reviewed `RetentionDecision`/resolver separate from request/template values. It binds operation/caller/scope, source/destination, allowed material (full body or explicitly defined minimal support), policy version/digest, reviewer identity, issued/expiry times, and revalidation rules. Missing/unavailable/mismatched/expired policy returns HOLD and stores neither output nor prohibited body. `source_rights` remains descriptive provenance only.
4. **P4 — shared HTTP integration.** Capture successful `FetchOutcome.body` inside the shared fetch/capture layer before WebsiteToText discards it, and return artifact identity plus retrieval metadata without headers. Both WebsiteToText and a standalone graph-free entrypoint must call this exact function. Do not create a second fetcher or a Website-only store.
5. **P5 — exact extraction spans.** Replace `_extract_text`'s string-only return with an extraction result containing normalized text plus ordered nonempty raw-byte/normalized ranges. Define encoding and half-open offset units explicitly. Fail closed to REVIEW/revalidation when exact mapping cannot be established; do not fabricate a whole-document span or approximate offsets.
6. **P6 — TemplateEnricher integration.** Route its already-buffered response bytes through the same capture/resolver and reviewed retention decision. Replace arbitrary `source_rights != unspecified` admission. Keep secret-header assembly at dispatch only and add recursive denial tests proving header names/values, URL credentials/query secrets, and raw bodies never enter bundles, `Scan.details`, `EvidenceEnvelopeRecord`, diagnostics, logs, or API reports.
7. **P7 — explicit recovery states.** On resolve: missing locator/body, expired authorization, digest mismatch, truncated/incomplete capture, or unsupported span mapping must produce an explicit REVIEW/revalidation result; retention authority unavailable/missing is HOLD. Digest mismatch must never return bytes. Preserve old records and lineage; re-fetch/revalidation creates a new immutable snapshot rather than rewriting digest/locator.
8. **P8 — sinks/adoption.** Add a dedicated lossless bundle/artifact importer only if durable integrated adoption is required. Do not expand `persist_structured_result` implicitly. Legacy Website task/orchestrator may continue receiving normalized outputs, but artifact bodies/capabilities stay outside outputs/cache/report JSON. The template task/report receives identifiers/digests/status only.

## Boundary invariants and acceptance tests

- **I1 Authorization:** possession of an artifact ID, locator, bundle, request, or digest grants nothing. Resolution requires exact operation ID + caller ID + scope/policy match at call time.
- **I2 Redaction:** bundles/reports/logs/cache keys contain no request/response headers, cookies, credentials, bearer material, vault values, raw URL userinfo, or resolver/store capability. Test recursively, including failure text.
- **I3 Integrity:** SHA-256 is computed from the complete stored bytes, verified again on resolve, and matches artifact/bundle digests. Digest tamper returns REVIEW/revalidation and no bytes.
- **I4 Completeness:** declared/chunked overflow or interrupted capture stores no body as complete. If policy permits minimal support, its exact selection rule and truncation state are recorded; otherwise HOLD/REVIEW.
- **I5 Retention:** only a reviewed, unexpired runtime retention decision authorizes storage. Template `source_rights`, caller fields, or a digest without the resolved decision never authorize retention. Resolver unavailable is HOLD.
- **I6 Spans:** raw offsets use original stored bytes; normalized offsets use one declared unit/encoding; ranges are half-open, ordered, bounded, and reproduce the cited normalized substring exactly.
- **I7 Dedup/lineage:** identical bodies share one content object, but every input occurrence keeps its own occurrence ID, input ref, operation, retrieval metadata, span/evidence/candidate ownership, and outcome. Completion order and cache reuse cannot collapse occurrences.
- **I8 Recovery:** missing, unavailable, expired, tampered, or truncated artifacts are explicit REVIEW/revalidation; no silent empty success, fallback locator, positional association, or automatic re-fetch.
- **I9 Shared implementation:** standalone and WebsiteToText tests spy on the same capture/resolve symbols and exercise real stored-byte round trips. TemplateEnricher uses those symbols too, with its own endpoint authorization intact.
- **I10 Compatibility:** current acquisition tests at `flowsint-core/tests/acquisition/test_contract.py:157-407` continue to enforce duplicates, reference graph, digest mutation, ownership, holds, versioning, and safe errors. Add `test_artifact_capture.py` for authorization/dedup/resolve/recovery; extend `test_fetch.py`, `test_website_to_text.py`, `test_template_enricher.py`, `test_template_execution_task.py`, `test_execution_service.py`, and `flowsint-api/tests/test_template_egress.py` at their existing public boundaries.
