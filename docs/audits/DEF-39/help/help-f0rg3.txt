Usage: f0rg3 [options] [command]

Unified power tools for code intelligence, research, and shipping

Options:
  -V, --version                                      output the version number
  --config <path>                                    Config file override
  --no-color                                         Disable colors
  --log-level <level>                                Log level (debug|info|warn|error) (default: "warn")
  -v, --verbose                                      Debug output (alias for --log-level debug)
  -q, --quiet                                        Errors only (alias for --log-level error)
  -h, --help                                         display help for command
