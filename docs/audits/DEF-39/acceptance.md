## Findings (stable ids)

- **DEF39-F1 (high, confidence high)** `blast`/`Blast-native` default `--auto-index=true` silently rewrites the shared `.gitnexus/` on a read-only audit. Observed. Mitigation in procedure: mandatory `--no-auto-index`.
- **DEF39-F2 (medium, high)** Every upstream blast on fl0sint reports `query-interrupted` → `risk UNKNOWN`, even with edges found; not reproducible on a small repo. Blast is currently *partial evidence* on this codebase.
- **DEF39-F3 (medium, high)** Registry/dynamic dispatch is invisible: `WebsiteToText` upstream 0 edges; `get_enricher` downstream reports `LOW/complete` with 0 edges (false comfort); `Enricher.execute` has no incoming CALLS from `run_enricher`.
- **DEF39-F4 (medium, high)** Stale-index-without-flag: after a new commit on the disposable repo, `--no-auto-index` blast returned `complete/ready` while `--drift` showed `symbol_stale 2`. Procedure requires `--drift total == 0` before trusting a `--no-auto-index` blast.
- **DEF39-F5 (low, high)** `graphos --refs <Class>` exits 1 on `METHOD_OVERRIDES` (schema enum lag vs index). Cypher workaround documented.
- **DEF39-F6 (low, high)** `doctor --hunt` coverage 0 / self-contradictory finding; `doctor --verify-refactor` ignores blast completeness.
- **DEF39-F7 (low, high)** Exit code 0 for unresolved symbol / missing index / unusable `--lbug-path`; `indexStatus ready` reported for an unusable `--lbug-path` directory.
- **DEF39-F8 (info)** `pip3r-graphos` producer writes `lastCommit: ""`; HEAD-pinning must be done by the operator (worktree/clone + isolated index), freshness is generation-hash + drift.

Checked clean: help text vs accepted flags (all flags used were in `--help`); standalone vs native parity (byte-identical on 4 paired runs); tracked source and git state; `parse-cache/`, `parsedfile-cache/`, `run.cjs` unchanged.

Overall verdict for the stated scope: **pass_with_observations** on tooling capability (i, ii, iv), **fail** on fixture iii-b (shared coordination state was rewritten by auto-index). No remediation was performed; this packet does not authorize any.
